# Footprinting and Scanning

This repository contains my practical work and documentation on **footprinting, information gathering, and network scanning**.

The exercises were carried out using different cybersecurity tools to understand how information about systems, domains, and networks can be collected and analyzed during the reconnaissance phase of cybersecurity.

## 📂 Contents

### `HARVESTER/`
Contains practical work involving **TheHarvester**, a reconnaissance tool used to gather publicly available information such as email addresses, hostnames, domains, and other information associated with a target.

### `KALI TOOLS/`
Contains practical exercises and materials involving **Kali Linux cybersecurity tools** used for reconnaissance, information gathering, and security testing.

### `SCAN/`
Contains practical work related to **network scanning**, including identifying hosts, open ports, and available services on a network.

### `CMDX.PNG`
A screenshot documenting one of the practical exercises completed during the task.

### `MALTEGO.PNG`
A screenshot of practical work carried out using **Maltego**, a tool used for gathering and visualizing relationships between publicly available information.

### `Report.pdf`
Contains the documented report of the practical activities and findings.
